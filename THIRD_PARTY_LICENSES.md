# Third-Party Licenses

LAMINARIA currently contains no vendored third-party source or distributed third-party binary.

As dependencies, generated code, vendored sources, or redistributed toolchain components are introduced, this file must identify each distributed component, its version or source revision, its license, and any required attribution or notice text.

Rust and Nim package metadata must declare the same project expression: `MIT OR Apache-2.0`. Dependency licensing must be checked before a release artifact is distributed.
